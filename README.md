# study-buddy
Study together, without the small talk.
A virtual study desk for students who study alone. Join a room,
focus with a Pomodoro timer, and chat is locked while you focus.

Live demo: https://lynnbui07.github.io/study-buddy/

## Tech
HTML, CSS, JavaScript, Firebase Realtime Database.
Best on desktop and tablet (landscape).
